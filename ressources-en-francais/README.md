# Ressources en français 🇫🇷

Sélection de ressources **gratuites** et **en français**, pour apprendre sans barrière de langue.

## Plateformes d'apprentissage

| Ressource | Description | Domaine | Niveau |
| --- | --- | --- | --- |
| [Zeste de Savoir](https://zestedesavoir.com) | Tutoriels et cours rédigés par la communauté, plateforme elle-même [open source](https://github.com/zestedesavoir/zds-site). | Programmation, web, sciences | Tous niveaux |
| [France-IOI](https://www.france-ioi.org) | Cours et milliers d'exercices d'algorithmique corrigés automatiquement. | Algorithmique | Débutant → Avancé |
| [Pix](https://pix.fr) | Évaluer et développer ses compétences numériques (service public). | Bases du numérique | Débutant |
| [FUN MOOC](https://www.fun-mooc.fr) | MOOC des universités et écoles françaises (informatique, réseaux, data…). | Tous domaines | Tous niveaux |
| [OpenClassrooms](https://openclassrooms.com/fr/) | Nombreux cours gratuits en ligne (certificats payants). | Tous domaines | Débutant |
| [Grafikart](https://grafikart.fr) | Tutoriels vidéo gratuits sur le développement web. | Web | Débutant → Intermédiaire |

## Documentation officielle en français

| Ressource | Description |
| --- | --- |
| [MDN Web Docs (FR)](https://developer.mozilla.org/fr/) | La référence HTML, CSS et JavaScript. Traductions maintenues sur [mdn/translated-content](https://github.com/mdn/translated-content). |
| [Tutoriel Python officiel (FR)](https://docs.python.org/fr/3/tutorial/) | Documentation Python traduite par la communauté sur [python/python-docs-fr](https://github.com/python/python-docs-fr). |
| [Documentation Ubuntu francophone](https://doc.ubuntu-fr.org) | Wiki très complet pour apprendre Linux et l'administration système. |

## Réseaux, systèmes et cybersécurité

| Ressource | Description | Niveau |
| --- | --- | --- |
| [Cisco Networking Academy](https://www.netacad.com) | Cours réseaux, CCNA, Linux et cybersécurité, dont plusieurs gratuits et disponibles en français. | Débutant → Avancé |
| [IT-Connect](https://www.it-connect.fr) | Tutoriels gratuits sur les réseaux, Windows Server, Linux et la sécurité. | Tous niveaux |
| [SecNumacadémie (ANSSI)](https://secnumacademie.gouv.fr) | MOOC officiel de l'ANSSI sur la sécurité numérique, avec attestation. | Débutant |
| [MOOC de l'ANSSI](https://cyber.gouv.fr/mooc) | Présentation des formations en ligne de l'agence nationale de cybersécurité. | Débutant |
| [Root Me](https://www.root-me.org) | Plateforme française de challenges de sécurité, légaux et encadrés. | Intermédiaire |
| [Hackropole](https://hackropole.fr) | Archives des épreuves du France Cybersecurity Challenge (ANSSI), pour s'entraîner. | Intermédiaire → Avancé |
