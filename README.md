- 🗺️ **[Parcours d'apprentissage](learning-paths/)** : feuilles de route et cursus complets.

## Ajouter une ressource

1. Lire [CONTRIBUTING.md](CONTRIBUTING.md).
2. Copier le modèle [templates/RESOURCE_TEMPLATE.md](templates/RESOURCE_TEMPLATE.md).
3. Ajouter la fiche dans la catégorie correspondante (ex. `programming/python/python-official-tutorial.md`).
4. Ouvrir une Pull Request.

Pas à l'aise avec Git ? Ouvre simplement une [Issue « Proposer une ressource »](https://github.com/Omada-for-eureka/resources/issues/new/choose), un mainteneur s'en chargera.

## Règles

- Vérifier les liens.
- Décrire clairement la ressource.
- Indiquer le niveau et la langue.
- Privilégier les sources officielles.
- Respecter les licences et droits d'auteur : pas de copies piratées de livres, cours ou logiciels.
- Ne jamais publier de secrets ou de données privées.
