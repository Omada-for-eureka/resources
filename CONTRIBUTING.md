# Contribuer à la bibliothèque

Règles générales : [community-handbook/CONTRIBUTING.md](https://github.com/Omada-for-eureka/community-handbook/blob/main/CONTRIBUTING.md).

## Ajouter une ressource

1. Choisir la catégorie (voir [README.md](README.md)). Si le sous-dossier n'existe pas encore, le créer.
2. Copier [templates/RESOURCE_TEMPLATE.md](templates/RESOURCE_TEMPLATE.md) et le remplir.
3. Nommer le fichier en minuscules, sans espaces ni accents : `docker-getting-started.md`.
4. Ouvrir une Pull Request depuis une branche `docs/...`.

## Règles de classement

- Un fichier Markdown par ressource, ou une liste thématique (`README.md` du dossier) si les ressources sont très courtes.
- Noms de fichiers simples, en minuscules, sans espaces.
- Préférer un lien vers la source officielle plutôt que l'hébergement d'un fichier.
- Éviter les copies de contenus protégés.
- Mentionner la date de vérification lorsqu'une ressource évolue rapidement.
- Signaler les ressources obsolètes (ajouter `> ⚠️ Obsolète : …` en tête de fiche) plutôt que les supprimer sans explication.

## Critères de validation (mainteneurs)

- [ ] Lien fonctionnel.
- [ ] Source identifiable.
- [ ] Description utile.
- [ ] Catégorie correcte.
- [ ] Niveau et langue renseignés.
- [ ] Droits d'auteur respectés.
- [ ] Aucun secret ni donnée privée.

## Licences

Les ressources externes restent sous la licence de leur auteur : la fiche pointe vers la source et ne présente jamais un contenu comme libre si sa licence n'est pas connue.
